Final projects deliverables
Prepare a presentation (PDF or Jupyter notebook slides) and submit it to LMS

Present your results to course instructors and other students using the submitted Jupyter notebook/PDF presentation and other materials (if needed).
We request that you prepare prerecorded video presentations of your projects where team members describe all parts of the project (see grading) using your Jupyter / PDF presentation. For example, you can record it via a Zoom meeting.

Please add a link (e.g., to YouTube or cloud storage) during your submission in addition to code and presentation. We'll use team names to find & launch videos during the defense, so submit from the corresponding account. For example, team Doe should ask John/Jane to submit on behalf of the whole team.

Grading details
Describe the problem you want to solve using data science techniques. Why is it important? How can your ML model help (e.g., reduce costs, increase quality, etc.)? (4 points)
Load the data using pandas and split the data frame into X (inputs) and y (outputs). (2 points)
Prepare your dataset: encode categorical variables (if any), handle missing variables (if any), and generate new features (if you have some intuition that these features can be helpful). Preprocess the target variable if needed (e.g., combine various classification problems into a single one or convert the target variable to a binary one). For each transformation, give a clear explanation of your motivation. (5 points)
Perform an exploratory analysis of the data via visualization with Seaborn. Try to find meaningful patterns in the data that can be used to make a machine learning task more specific or to help with selection and tuning ML models. Perform additional data preprocessing if your findings suggest this (again, all steps should be motivated). If there are several options for target variables, you can select some of them after this step with a couple of sentences explaining your choice. (4 points).
Build a proper cross-validation procedure; select an appropriate measure of quality (the selection of both things should be motivated by your data). Choose an ML model reasonably; look for a good set of hyperparameters. Use the prepared cross-validation procedure to estimate the quality of prediction (7 points).
Analyze the obtained results (interesting findings, remarks on ML experiments, the model's applicability in a real-life scenario) and make an overall conclusion. Does your model solve the problem stated at the beginning? Can you estimate the impact of your ML model on the problem domain (8 points)?
Also, we'll estimate the structure and clarity of your presentations (10 points).
